## How to Use This Phase

Each chapter follows the **4-step interview framework** from Chapter 5:

1. **Requirements** — Functional + Non-functional
2. **Estimation** — QPS, Storage, Bandwidth
3. **High-Level Design** — Architecture diagram + APIs
4. **Detailed Design** — Deep dives into critical components

**Practice approach:** For each problem:
- First, try to design it yourself in 45 minutes (simulate an interview)
- Then read the chapter to compare your design
- Note what you missed and what you got right
- Re-attempt the design from memory 3 days later
