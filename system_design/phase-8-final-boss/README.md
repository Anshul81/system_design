## How to Use This Phase

This phase is different from Phases 6-7. Instead of learning new system designs, you're learning how to **perform** in the interview:

1. **Read each chapter once** — internalize the frameworks
2. **Do mock interviews** — practice with a friend, time yourself to 35-40 minutes
3. **Review after each mock** — check which anti-patterns you fell into
4. **Re-read the night before** — these are your cheat sheets
