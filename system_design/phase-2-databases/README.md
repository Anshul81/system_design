# 🗄️ Phase 2 — Databases & Storage

> *Every system stores data. Choosing the right database and designing the right schema is often the make-or-break decision in a system design interview.*

**⏱ Estimated Time: ~13 hours**

## What You'll Learn

- ✅ Choose between SQL and NoSQL with reasoned trade-offs
- ✅ Design database schemas and sharding strategies
- ✅ Explain replication, consistency models, and the CAP theorem
- ✅ Know when to use Redis vs Cassandra vs PostgreSQL vs S3
- ✅ Design indexing strategies for read-heavy systems

---

## Checkpoint Exercise

1. Design the database schema for Twitter
2. Explain when you'd shard vs replicate
3. Walk through consistent hashing for a database cluster
